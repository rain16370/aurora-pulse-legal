## 一句话简介

AURORA·PULSE极光脉冲 是一款**完全离线运行**的单机音乐节奏游戏：25 首曲目、EZ / HD / IN 三档难度共 75 张谱面，动态判定线随旋律倾斜旋转，六种音符（TAP / HOLD / DRAG / FLICK / PULSE / TRACE）各自带有不同的读谱语言。

- 无账号、无联网、无内购、无广告、无排行榜；
- 不申请任何 Android 权限（v1.0.7 包体经 `aapt2` 校验为 0 项权限）；
- 不收集、不上传、不共享任何个人信息；
- 游戏进度与成绩仅以文本文件保存在玩家本机，卸载即删除。
